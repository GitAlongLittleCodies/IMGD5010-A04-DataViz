What I set out to do was to look at the Top 10 Overtime Pay earners in the MontgomeryData 2024 Employee Salary dataset. The dataset has over 10,000 records and the API returns only 1,000 records at a time, max. I might have spent as much time learning how to manipulate the dataset generated by the source as I did to visualize the data. Still, I couldn't sort the data and could only use it in the sequence provided - which doesn't appear to be in any particular order to start with. Had I sorted the data, I would have tried a few more approaches to help visualize the counter-intuitive ratio these people make in base to overtime pay.
