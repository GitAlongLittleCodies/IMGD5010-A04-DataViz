# IMGD 5010 &bull; Assignment 04: Data Visualization

### [Sketch & Edit](https://editor.p5js.org/GitAlongLittleCodies/sketches/h1oQibN9k) -or- [Sketch Only](https://editor.p5js.org/GitAlongLittleCodies/full/h1oQibN9k)

What I set out to do was to look at the **Top 10 Overtime Pay Earners** in the **MontgomeryData Employees Salaries - 2024**[^1] dataset. 

There are over 10,000 records in the set *and* the API returns only 1,000 records at a time, no more. I might have spent as much time learning how to manipulate the dataset generated by the source as I did to visualize the data. While I could not sort the data, I could filter it. By filtering my selection to records that had overtime pay over $145,000, I was able to limit my results to just 10 records, unsorted. These records do, in fact, represent the **Top 10 Overtime Pay Earners** in 2024 for Montgomery County, Maryland. 

I successfully completed all the steps of the assignment: improved my skills using JSON, arrays, loops, and how to load external data. I gave a lot of thought about trying to represent the data through an abstract process. I think my coding limitations are the reason why I couldn't elevate the visuals or even build in an interactive element. This visualization still lacks the impact I would like to extract from the data. Somebody making $400,000 a year with over 66% of it coming form overtime seems odd to say the least. Yet to present it in barchart form feels like I reduced it to an image for a Powerpoint presentation. However, I am happy that I was able to make a clean graph using p5js.
